# me2resh skills

Agent skills by Ahmed Mohamed. Each one lives in its own repo with its own page, examples and versions. This repo is the catalogue: add it once, then install any of them.

```
/plugin marketplace add me2resh/skills
/plugin install cold-read@me2resh-skills
/plugin install field-read@me2resh-skills
/plugin install tayyib@me2resh-skills
/plugin install job-apply@me2resh-skills
```

| Skill | What it does | Page |
|---|---|---|
| [Cold Read](https://github.com/me2resh/cold-read) | Read any company from the outside before you invest, join or buy it. Every claim marked cited, inferred or unknown. | https://me2resh.github.io/cold-read/ |
| [Field Read](https://github.com/me2resh/field-read) | Read a whole field, or compare two, from the public record. Dated scenarios with falsifiers, every claim marked. Sibling of Cold Read. | https://me2resh.github.io/field-read/ |
| [Tayyib](https://github.com/me2resh/tayyib) | A hard halal gate for any financial product or employer, to the AAOIFI standard. One verdict, the ratios, two sources that must agree. | https://me2resh.github.io/tayyib/ |
| [Job Apply](https://github.com/me2resh/job-apply) | Tailored job applications that are true in every line, from a fact bank you build once. | https://me2resh.github.io/job-apply/ |

Codex, Cursor and GitHub Copilot are supported too; each skill's README has the steps.
